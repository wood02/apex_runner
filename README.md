# Apex Runner

Apex Runner 是一个面向 Windows 游戏场景的迷你启动器，适合 Apex Legends、CS2、Minecraft 等对中文输入法或系统快捷键支持不够稳定的游戏。

它的目标很简单：进游戏前一键切到更安静的操作环境，退出后再快速恢复日常设置。

## 功能

- 一键禁用或恢复 Windows 键，减少游戏中误触弹出开始菜单。
- 一键切换中文/英文输入法，避免聊天、开火或移动时被中文输入法打断。
- 一键禁用或恢复 Alt+Shift / Ctrl+Esc 相关快捷键。
- 右键 `一键优化` / `一键恢复` 可分别设置两套方案，包括 Win 键、输入法、Alt+Shift 和声音输出。
- 快速启动加速器、语音软件和 Steam。
- 快速打开 Windows 显示设置和应用音量设置。
- 支持选择声音输出设备，并在一键优化/恢复时切换默认输出。
- 支持自定义全局快捷键，默认快捷键为 `Ctrl + Alt + K`。
- 支持启动时自动一键优化、关闭时自动一键恢复。

## 系统要求

- Windows 10 或 Windows 11
- .NET Framework 4.7.2 或更高版本
- 某些游戏或系统级快捷键屏蔽功能可能需要以管理员身份运行

## 使用说明

1. 从 Releases 下载压缩包并解压。
2. 运行 `apex runner.exe`。
3. 在路径设置中填写常用程序路径：
   - 加速器路径
   - 语音软件路径
   - Steam 路径
4. 选择当前手动控制项：
   - Windows 键：启用 / 禁用
   - 输入法：中文 / 英文
   - Alt+Shift：启用 / 禁用
   - 声音输出设备
5. 右键 `一键优化`，设置进入游戏时要应用的方案。
6. 右键 `一键恢复`，设置退出游戏后要恢复的方案。
7. 点击 `一键优化` 进入游戏状态。
8. 游戏结束后点击 `一键恢复` 回到日常状态。

## 右键方案

`一键优化` 和 `一键恢复` 是两套独立配置。右键按钮后可以选择：

- Win 键：启用 / 禁用
- 输入法：中文 / 英文
- Alt+Shift：启用 / 禁用
- 声音输出：设备 1 / 设备 2

例如，你可以把 `一键优化` 设置为禁用 Win 键、切英文输入法、禁用 Alt+Shift、切到耳机；把 `一键恢复` 设置为启用 Win 键、切回中文输入法、启用 Alt+Shift、切回音箱。

## 快捷键

默认全局快捷键是：

```text
Ctrl + Alt + K
```

点击 `点击识别` 后按下你想使用的组合键，再点击 `保存按键` 即可修改快捷键。

快捷键触发后会在优化和恢复状态之间快速切换，适合游戏前后不想手动点窗口的场景。

## 常见问题

### Windows 键禁用没有生效

请尝试右键 `apex runner.exe`，选择“以管理员身份运行”。如果游戏本身以管理员权限运行，Apex Runner 也需要相同或更高权限才能稳定拦截。

### 输入法没有切换成功

请确认系统中已经安装英文输入法，并且当前 Windows 输入法设置允许应用切换输入语言。

### 声音输出设备没有显示

Apex Runner 只显示当前可用的活动输出设备。请先在 Windows 声音设置中确认设备已连接并启用。

## 从源码构建

1. 安装 Visual Studio，并勾选 `.NET 桌面开发` 工作负载。
2. 打开 `apex runner.sln`。
3. 选择 `Release` 配置。
4. 点击生成解决方案。
5. 编译产物位于：

```text
apex runner/bin/Release/
```
